# NAPAS - Health & Focus Dashboard

Dashboard pemantauan kesehatan mental, ritme fokus, dan manajemen tugas dengan antarmuka modern, interaktif, dan responsif.

## ✨ Fitur Utama
- **Indikator Skor Kesehatan**: Pengukur lingkaran interaktif (Zona Waspada: Hijau) dengan perbandingan progres harian.
- **Analisis Faktor ("Kenapa skor ini?")**: Insight detail durasi tidur, distraksi, deadline, dan kedipan mata, lengkap dengan accordion detail tambahan.
- **Mood Check-In**: Pilihan suasana hati harian (Bahagia, Netral, Sedih) dengan feedback interaktif dan notifikasi toast.
- **Latihan Pernapasan (Breathing Mode)**: Animasi ritme pernapasan paru-paru (Tarik Napas, Tahan, Hembuskan) dengan panduan visual.
- **Deadline Terdekat & Manajemen Tugas**: Daftar tenggat waktu terdekat dengan modal dialog pop-up untuk menambahkan tugas baru secara dinamis.
- **Desain Responsif**: Mendukung layar desktop, tablet, dan smartphone dengan mobile drawer dan bottom navigation bar.

## 🚀 Menjalankan Secara Lokal
Cukup buka file `index.html` di browser favorit Anda, atau jalankan server lokal:
```bash
python -m http.server 3000
```
Buka di browser: `http://localhost:3000`

## 🛠️ Teknologi
- HTML5 (Semantik)
- Vanilla CSS (Responsive Grid & Flexbox, Keyframe Animations)
- Vanilla JavaScript (Micro-interactions, Modal, Toast)
- Google Fonts (Poppins)
